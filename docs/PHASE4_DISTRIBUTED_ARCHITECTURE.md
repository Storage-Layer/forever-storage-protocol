# Phase 4 Distributed Architecture
Components: `fsp-node` daemon ([daemon.rs](file:///home/rade/Project/Jobs/fsp/src/node/daemon.rs)), mTLS RPC server/client ([server.rs](file:///home/rade/Project/Jobs/fsp/src/network/server.rs), [client.rs](file:///home/rade/Project/Jobs/fsp/src/network/client.rs)), coordinator ([transactions.rs](file:///home/rade/Project/Jobs/fsp/src/coordinator/transactions.rs)), placement ([placement.rs](file:///home/rade/Project/Jobs/fsp/src/coordinator/placement.rs)), repair scheduler + scrubber ([scheduler.rs](file:///home/rade/Project/Jobs/fsp/src/coordinator/scheduler.rs)).
The coordinator is a **single point of failure** (no replication/consensus). Metadata = Ed25519-signed manifests under `<coord_root>/manifests`, journal under `journal/`. Nodes own their storage root (`.fsp-node-marker`), identity, journal, shard index.
Placement: failure-domain caps per policy; fails explicitly if unsatisfiable. In single-host tests all nodes share one physical host, so `MultiHostDistinctMachines` correctly refuses placement.
