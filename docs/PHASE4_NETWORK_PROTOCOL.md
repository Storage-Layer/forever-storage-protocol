# Phase 4 Network Protocol (v1)
Frame: `FSPN` | version u16 LE | meta_len u32 | payload_len u32 | meta (UTF-8 key=value lines) | payload. Limits: meta 256 KiB, payload 32 MiB, checked before allocation. Version mismatch and bad magic rejected. Ops: PutShard, GetShard, DeleteShard, VerifyShard, ListShards, Heartbeat, GetNodeStatus. One request per TLS connection. Transport: TLS 1.3 only (rustls/ring), mutual auth. Known weaknesses: text meta parser uses `unwrap_or` defaults for some numeric response fields; error-code mapping on the client loses detail (e.g. ShardNotFound fields).
