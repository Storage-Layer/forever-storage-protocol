# Phase 4 Signed Manifests
Ed25519 over domain-tagged canonical bytes (`FSP-MANIFEST-SIG-V1` + signer, alg, pubkey, generation, manifest fields + canonical JSON). `TrustedSignerPolicy` pins signer->pubkey and keeps a per-object generation watermark (replay of older generation rejected). `MetadataBackupBundle` is signed and verified before restore. Limitations: watermark is in-memory (rebuilt from on-disk manifests at start; a wiped coordinator can be rolled back to an older validly signed manifest unless a bundle/watermark is kept elsewhere); no key rotation or revocation; signer seed in tests is a fixed constant.
